AI 接入（MCP）

这是什么

MCP server 是开发 AI 读取本系统的只读通道：它以 stdio 方式跑在开发机上， 作为 Claude Code 等 AI 客户端的本地插件进程启动。AI 只能读取已发布版本的文档 （支持版本 pin 锁定快照），没有任何修改文档的工具；发现文档有误时只能通过 提案通道提交建议，经人审批发布后才生效。
